# 🛒 Gadget Shop | Smart Gadgets, Laptops & Tech Services

> **Nigeria's Premier Certified Pre-Owned & Brand-New Tech Hub**

Gadget Shop is a modern e-commerce platform and administrative diagnostics ecosystem specializing in smartphones, laptops, audio gear, and technical hardware repairs.

---

## 🌟 Key Features

### 🛍️ Customer Storefront
- **Flagship Gadget Catalog**: Pre-owned (London Used, Grade A Pristine) and brand-new devices with battery health percentages and cosmetic grading.
- **Dynamic Color Variant Switching**: Interactive finish swatches update product imagery in real-time.
- **Rich Product Information**: Multi-tab layout featuring comprehensive descriptions, technical specifications, box contents, and 45-point diagnostics reports.
- **Checkout & Regional Logistics**:
  - Configurable delivery zones (Lagos Mainland, Lagos Island/Lekki, Abuja, Port Harcourt, Nationwide).
  - Free in-store pickup at Ikeja Tech Hub.
  - Multi-channel payments: Direct Bank Transfer (with instant receipt proof upload) and Card Gateways.
- **Commercial Tax Invoice & Proof of Purchase**:
  - Itemized table with device specs, IMEI / serial number, and accessories.
  - 45-point hardware diagnostics guarantee certified by Lead Diagnostics Officer.
  - Official 1-Year hardware warranty certificate.
  - Native `@media print` styling for 1-page A4 printing and PDF generation.

### 🛡️ Enterprise Admin Portal (`/admin`)
- **Dashboard**: Live metrics on gross merchandise value, order volume, pending payment audits, and repair jobs.
- **Product Management**: Media uploader supporting a Primary Hero Picture plus up to 5 Sub-Pictures with color-variant linkage and rich descriptions.
- **Order Tracking & Dispatch**: Real-time status progression, rider allocation, and waybill printing.
- **Payments Tracker**: Transaction logs, transfer receipt audit modal, and payment status toggling.
- **Promos & Vouchers**: Percentage or fixed discount coupons with usage limits and expiration dates.
- **Diagnostics & Services**: Multi-stage repair tracking (Received, Bench Work, Tested, Ready).
- **Customer Directory**: Customer spend histories, wallet balances, and direct WhatsApp contact.
- **Logistics & Store Settings**: Configurable shipping zone fees and store bank accounts.

---

## 🛠️ Tech Stack

- **Frontend**: Vite 8 + React 18 + TypeScript
- **Routing**: React Router DOM v6
- **Styling**: Tailwind CSS + Custom Media Print Queries
- **Icons**: Lucide React
- **State Management**: React Context (`AdminContext`, `CartContext`, `AuthContext`, `OrderContext`)
- **Build Tool**: Vite (`npm run build`)

---

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

Open [http://localhost:5173](http://localhost:5173) to view the platform in your browser.
